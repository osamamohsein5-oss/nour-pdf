# نور PDF

قارئ PDF مستقل ومفتوح المصدر بواجهة عربية. الاسم والهوية البصرية والشيفرة الخاصة بالتطبيق مستقلة؛ محرك قراءة PDF هو PDF.js من Mozilla.

## الميزات الأولية

- فتح ملفات PDF محليًا من الجهاز.
- عرض صفحات طويل مع تحميل الصفحات القريبة من موضع القراءة عند الحاجة.
- التنقل بين الصفحات، التكبير والتصغير، والملاءمة مع النافذة.
- البحث النصي داخل المستند وحفظ نسخة منه.
- واجهة عربية مع وضع فاتح وداكن.
- لا يُرسل المستند إلى خادم.
- تثبيت اختياري للمستخدم على Windows 64-bit.

## التشغيل والبناء

يتطلب Node.js 22 أو أحدث على Windows 64-bit.

```powershell
npm install
npm run dev
```

لإنشاء مثبت Windows:

```powershell
npm run dist
```

يظهر المثبت في مجلد `release/`.

## التراخيص

شيفرة التطبيق الأصلية مرخصة MIT. PDF.js مرخص Apache-2.0، وتُدرج إشعاراته وملفات ترخيص التبعيات ضمن الحزمة. هذا المشروع مستقل وغير تابع إلى Adobe.
